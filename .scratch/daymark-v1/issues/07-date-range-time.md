# 07: 日期区间与具体时刻

**What to build:** Daymark 支持两种日期形态扩展:①日期区间(开始+结束),追踪一段活动(旅行/展会),列表与详情显示区间及"已开始 N 天/还剩 N 天/已结束";②具体时刻(hasTime),创建/编辑时可给日期附带时间,提醒落在该时刻而非默认时刻。

**Blocked by:** 03 面板导航:详情/编辑/删除/空态;05 提醒通知

**Status:** ready-for-agent

- [ ] 表单支持切换单日 ↔ 区间;区间时结束日 ≥ 开始日校验
- [ ] 区间状态判定进 DateMath(未开始/进行中/已结束,含进度天数),测试覆盖当天开始、当天结束、跨月区间
- [ ] 详情与列表文案适配区间(如"进行中 · 第 3 天/共 5 天")
- [ ] 表单时间开关(hasTime),开启时 DatePicker 含时刻
- [ ] 有时刻的 Daymark 提醒落在该时刻;无时刻仍落默认时刻(与 05 票行为衔接,假调度器测试)
- [ ] 区间 + 重复组合有定义良好的行为(建议:重复仅按开始日滚动,测试钉死)
